# Code of Conduct

## Our standard

Contributors should make participation safe, respectful, and useful. Expected behaviour includes:

- treating people with dignity across identity, background, experience, and ability;
- critiquing ideas and evidence without attacking people;
- accepting correction and acknowledging uncertainty;
- protecting private, sensitive, and bystander information;
- respecting boundaries, consent, licences, and the project's non-authoritative status;
- stopping behaviour when someone says it is unwelcome.

Harassment, threats, discrimination, sexualised attention, doxxing, stalking, intimidation, and deliberate disclosure of private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other spaces where someone represents this project.

## Reporting and platform safety

Do not post sensitive conduct reports or personal details in a public issue. Use GitHub's private reporting, block, and Report Abuse features where applicable. If the repository owner exposes a private, monitored contact method on their GitHub profile or repository settings, use that channel.

This project does not claim an investigation SLA or formal adjudication service. Repository maintainers may remove content, lock threads, reject contributions, or restrict participation to protect the community and repository.

For immediate danger or unlawful conduct, contact the appropriate local or platform authority; this project cannot provide emergency help.
