## 冲突、重复与陈旧风险

1. **无权威状态入口：** 原目录只有 brief，其 front matter 同时承担概念与状态。影响是后续读者可能把旧概念状态当当前状态。最小修复：以根目录 `STATUS.md` 为当前状态入口，并从各 gate 文档回链。
2. **假设与建议阈值混排：** brief 将 6/8、4/8 写成建议 Go 条件，却没有基线、样本依据或不确定性说明。影响是小样本容易被误读为统计证明。最小修复：G2 预注册“探索性决策阈值”，并保留原始逐人数据与反例。
3. **初始无版本/回滚机制：** 2026-08-29 时还不是 Git 仓库。该风险后来由 D-020 的公开 baseline Git 授权关闭；历史决策仍保留在 `DECISIONS.md`。

## 证据与引用规则

- 每个研究事实附来源标题、发布方、URL、访问日期；时效敏感信息记录 `verified_at`。
