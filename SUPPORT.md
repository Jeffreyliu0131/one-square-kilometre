# Support

Support is best-effort and limited to the public source repository:

- local installation and build reproduction;
- synthetic fixture validation;
- test and CI failures;
- documentation errors;
- accessibility or interaction defects in the synthetic prototype.

Open a GitHub issue with the exact commit, Node/pnpm versions, operating system, sanitised steps, and the smallest synthetic reproduction.

This project does not provide customer support, an SLA, emergency help, field operations, route/safety/accessibility advice, NUS support, real-data recovery, hosted service support, or production incident response.

For vulnerabilities, follow `SECURITY.md`. For conduct concerns, follow `CODE_OF_CONDUCT.md`. Never post secrets, private data, or sensitive reports in a public issue.
